## 1. 系统目标与支柱映射

### 1.1 系统目标

定义**唯一计分板**（市民满意度 `S`）的构成、tick 结算顺序与状态快照，使「玩家做了一个决策 → 若干 tick 后看到结果 → 能查到为什么」这条链成立。本系统同时是**全项目 tick 结算顺序的定义者**，其余四系统按第 3 节步序供数 / 取数。

### 1.2 支柱映射

| 支柱 | 本系统如何服务 | **本系统不得命中否决列的红线** |
| --- | --- | --- |
| **P1 满意度是唯一计分板** | `S` 是唯一终局量；人口、产值、建筑数只作为中间输入 | ❌ 不得引入与 `S` 并列且不折算的第二终局轴；❌ 不得给人口/建筑面积独立奖励 |
| **P3 城市是流动系统** | `f_c` / `f_s` / `f_e` 均**经通勤图**计算，不按静态半径 | ❌ 不得用「半径内即覆盖」；❌ 不得瞬时结算（所有结果随 tick 生效） |
| **P4 拇指宽的决读优先** | 对外只暴露 `S` 一个全局指标 + 归因链；4 因子进次级诊断面板 | ❌ 不得把 4 因子全摊在常驻 HUD（见 R3） |
| **P2 每笔投入都有机会成本** | `f_f` 由预算拨付驱动，投入不足会拉低 `S` | ❌ 不得出现无成本即可拉满 `f_f` 的路径 |

### 1.3 拍板约束核对（OD 全 A）

- **OD-1 A**：`S` 为唯一计分板、**无硬性终局**；周期末未达标可回退重试，绝不判负、绝不 Game Over。✅
- **OD-2 A**：默认暂停，玩家点「结束本日」结算一次 tick；本系统不自带自动播放。✅
- **OD-3 A**：本系统只产出聚合数据；「市民之声」文本由 05 消费本系统的归因链生成。✅
- **OD-4 A**：地图固定有限；本系统不假设地图可扩张到无穷。✅

## 3. 规则 / 数据结构

### 3.1 四因子定义（概念 2.1 R6 锁定的因子清单）

> **MVP 只有 R/C/I 三类分区、一类道路**（概念 5.1）。为避免引入「公共服务分区」（Should 期），四因子按以下方式从既有分区推导：居住→产业 = 上班流；居住→商业 = 生活服务流；产业→居住 = 环境暴露；预算拨付 = 公共服务投入。**不新增任何分区类型。**

| 因子 | 名称 | 数据来源 | 单位 | 归一化范围 |
| --- | --- | --- | --- | --- |
| `f_c` | 通勤可达因子 | 03 的 `T_c`（平均上班通勤时长） | 输入 `min`；因子无量纲 | `[0,1]` |
| `f_s` | 服务覆盖因子 | 03 的通勤图上「居住格 → 商业格」可达性 | 输入 `min` / `person`；因子无量纲 | `[0,1]` |
| `f_e` | 环境负荷因子 | 02 的产业分布 + 03 的通勤图距离 | 输入 `LU`（负荷点）；因子无量纲 | `[0,1]` |
| `f_f` | 财政投入因子 | 04 的 `I_f`（已拨付公共服务投入） | 输入 `CU/周期`；因子无量纲 | `[0,1]` |

### 3.2 状态快照 `Snapshot_t`（V2 诊 与 05 的数据底座）

```
Snapshot_t = {
  tick_index        : int,                      // 1 tick = 1 游戏日
  f[4]              : float[4],                 // 四因子，各 ∈ [0,1]
  S                 : float,                    // 综合满意度，分，∈ [0,100]
  dS                : float,                    // ΔS（归因分解量）= clamp(ΣΔS_i + ΔS_penalty)，分/tick；见 4.3 口径声明
  dS_by_factor[4]   : float[4],                 // 逐因子贡献 ΔS_i，分/tick（归因链）
  T_c               : float,                    // 平均通勤时长，min（来自 03）
  T_s               : float,                    // 平均生活服务可达时长，min（来自 03）
  E                 : float,                    // 环境负荷，LU
  I_f               : float,                    // 本周期已拨付投入，CU/周期（来自 04）
  input_version     : int                       // 暂停态编辑合并后的输入版本号
}
```

**保留策略**：至少保留 `Snapshot_{t-1}` 与 `Snapshot_t` 双帧；归因链 `dS_by_factor` 必须由双帧差分计算，不可事后估算。存储策略**已由 `docs/architecture/architecture.md` §11.6 A-2 确认**（自包含 `TickSnapshot` 含双帧 + `Δ_t` + 归因链 + 命令溯源，结算时记录、查询只读不重算；详见 8.2）。

> **ΔS 取值口径（T-113 裁定，推导见 4.3）**：共享数据字典（`design/gdd/systems-index.md` §4.2）中的 `ΔS` 是「满意度 tick 差分」的**概念项**；本 GDD 规定它的**实现载体 `Snapshot.dS` 取归因分解量** `clamp(ΣΔS_i + ΔS_penalty, −100, 100)`，而非 `S_t − S_{t−1}`。`S` 的绝对变化由本 tick 的 Delta 条目（`S: S_{t−1} → S_t`，实现已当帧产出）承载，**不新增共享符号、不改动只读的 `systems-index.md` §4.2**。两个量相差一个二阶交叉项（4.3），**不要求数值恒等**；AC-F2 的残差阈值只约束分解式内部。

### 3.3 tick 结算顺序（本系统定义，其余系统遵守；与 systems-index 4.3 一致）

```
S0 冻结输入：合并暂停态编辑队列，锁定 input_version
S1 02 → 输出地块状态 / OD 需求（q_od）
S2 03 → 求解通勤图，输出 T_c、T_s、各路段 q/cap
S3 计算四因子 f_c / f_s / f_e / f_f（f_f 取「上一周期已拨付」值，见 3.4）
S4 合成 S_t，计算 ΔS 与 dS_by_factor[4]
S5 写 Snapshot_t（保留 t-1 双帧）
S6 05 → 生成 / 更新 / 消退议题（消费 dS_by_factor）
S7 若为本周期末 tick：04 用 S_{t-1} 结算收入与结余，做目标判定与解锁
S8 UX 刷新（S、结余、周期、议题列表），tick 结束
```

> **S7 使用 `S_{t-1}` 而非 `S_t`** 是 systems-index 3.3 裁定的「单 tick 滞后」，用于打破 D6 闭环，同时让「投入 → 见效」有可感知的滞后（D4）。

## 4. 核心算法 / 公式骨架

> **全部参数均为占位符**，由平衡阶段（垂直切片调优）确定。本节只锁定**结构、变量单位与取值范围原则**，不锁定数值。所有 `clamp(x, lo, hi)` 表示把 `x` 钳制到 `[lo, hi]`。

### 4.1 四因子计算

| 因子 | 骨架公式 | 变量与单位 | 取值范围原则 |
| --- | --- | --- | --- |
| `f_c` | `f_c = clamp(1 − (T_c − T_0)/(T_max − T_0), 0, 1)` | `T_c` 平均上班通勤时长 `[min]`（03）；`T_0` 自由流基线 `[min]`；`T_max` 不可接受阈值 `[min]` | `0 < T_0 < T_max < ∞`；`T_c ≤ T_0 → f_c = 1`；`T_c ≥ T_max → f_c = 0`；不可达时 `T_c = T_max` |
| `f_s` | `f_s = Σ_g ( w_g × a_g ) / Σ_g w_g`，其中 `a_g = clamp(1 − t_g/T_s,max, 0, 1)` | `g` 遍历居住格；`w_g = P_g` 该格人口 `[person]`（02）；`t_g` 该格到最近商业格的通勤图路径时长 `[min]`（03）；`T_s,max` 服务可达阈值 `[min]` | `a_g ∈ [0,1]`；`Σ w_g = 0` 时 `f_s = 0`（不除零）；`T_s,max > 0`；**必须走通勤图，禁止欧氏/静态半径** |
| `f_e` | `E = Σ_{i∈产业格} Σ_{g∈居住格} ( J_i × P_g / (1 + d(i,g)) )`；`f_e = 1 − clamp(E/E_max, 0, 1)` | `J_i` 岗位数 `[job]`；`P_g` 人口 `[person]`；`d(i,g)` 通勤图最短路径时长 `[min]`；`E` 负荷 `[LU]`；`E_max` 负荷上限 `[LU]` | `E_max > 0`；`f_e ∈ [0,1]`；距离用通勤图而非直线（P3）；聚合粒度（逐格 / 分区块）待定，见第 8 节 |
| `f_f` | `f_f = clamp(I_f / I_ref, 0, 1)`，`I_ref = i_ref × P_t` | `I_f` 本周期已拨付公共服务投入 `[CU/周期]`（04）；`i_ref` 人均参考投入 `[CU/(person·周期)]`；`P_t` 人口 `[person]` | `i_ref > 0`；`P_t = 0 → I_ref = 0 → f_f = 0`（不除零）；`I_f ≥ 0` |

### 4.2 满意度合成（含防主导策略结构）

```
g(f)  = f ^ α                                    // 凹变换，0 < α < 1，边际递减
L_t   = clamp( ( f_floor − min_i(f_i) ) / f_floor , 0, 1 )   // 短板惩罚，∈ [0,1]
S_t   = clamp( 100 × [ Σ_i ( w_i × g(f_i) ) ] × ( 1 − λ × L_t ) , 0, 100 )    // 单位：分
```

| 参数 | 含义 | 单位 | 取值范围原则 |
| --- | --- | --- | --- |
| `w_i` | 四因子权重（`i = c,s,e,f`） | 无量纲 | `w_i ∈ [0.10, 0.50]` 且 `Σ w_i = 1`；**任一权重不得 >0.5**，防单因子主导 |
| `α` | 凹变换指数 | 无量纲 | `α ∈ (0,1)`；越小边际递减越强 |
| `f_floor` | 短板阈值 | 无量纲 | `f_floor ∈ [0.2, 0.5]`；低于它的因子触发额外惩罚与对应议题 |
| `λ` | 短板惩罚强度 | 无量纲 | `λ ∈ [0, 0.3]`；不得让惩罚压过主项 |
| `S_t` | 综合满意度 | `分` | `[0,100]`，钳制 |

> **为什么这样设计（防主导策略 R2 / 满足 AC3）**：
> ① 凹函数 `g` 使「四因子均衡」优于「单因子拉满」，消除可算出的唯一最优配比；
> ② 短板惩罚 `L_t` 让任何一项塌掉都不能靠其他项掩盖；
> ③ `f_c/f_s/f_e` 全部依赖**通勤图上的位置与时序**，同样的分区配比摆在不同位置结果不同 → 解空间**情境化**，而非一个全局最优解。

### 4.3 归因链（供 V2 诊 与 05 消费，支撑 AC2）

```
ΔS_i = 100 × w_i × [ g(f_{i,t}) − g(f_{i,t−1}) ] × (1 − λ × L_{t−1})     // 主项贡献，分/tick
ΔS_penalty = S_{t−1} × [ (1 − λ × L_t)/(1 − λ × L_{t−1}) − 1 ]             // 短板惩罚变化贡献
ΔS   = clamp( Σ_i ΔS_i + ΔS_penalty , −100, 100 )
```

> **ΔS 取值口径声明（T-113 裁定 · 选 A 附补强）**
>
> 令 `M_t = Σ_i w_i g(f_{i,t})`（主项）、`P_t = 1 − λ L_t`（短板惩罚乘子）；以下推导均在 §4.2 的 `clamp` 生效**之前**。
>
> | 量 | 定义 | 载体 |
> | --- | --- | --- |
> | **`ΔS`（归因分解量，共享符号 `ΔS` 的实现取值）** | `ΔS ≡ clamp( Σ_i ΔS_i + ΔS_penalty , −100, 100 )` = `100[(M_t − M_{t−1})P_{t−1} + M_{t−1}(P_t − P_{t−1})]` | `Snapshot.dS` / `dS_by_factor[4]` / `dSPenalty` |
> | **`S` 的绝对变化**（本 GDD 局部记号 `ΔS_abs`，非共享符号） | `ΔS_abs = S_t − S_{t−1} = 100(M_t P_t − M_{t−1} P_{t−1})` | tick 的 Delta 条目 `S: prev → current`（实现已产出） |
>
> **二者之差恒为二阶交叉项**：`ΔS_abs − ΔS = 100 × (M_t − M_{t−1}) × (P_t − P_{t−1}) = 100 ΔM ΔP`。当主项与短板惩罚**同时大变化**时（如四因子由全 `0.5` 跳到 `[0, 0, 1, >0]`、`L` 由 0 跳到 1），该项可达数分（实现侧复现约 2 ~ 4 分，与占位参数 `λ = 0.1 / α = 0.5 / w_i = 0.25` 下的 `100 ΔM ΔP` 量级吻合）。**这是「一阶 + 惩罚变化」分解式的固有近似性质，不是实现缺陷，也不要求二者数值恒等。**
>
> **为何保留近似、不做精确可加分解**：`ΔS_i` 必须能逐项绑定到具体通勤线 / 覆盖片区 / 环境源 / 预算项（AC2、P4）。若显式补入 `ΔS_cross = 100 ΔM ΔP` 使 `ΔS = ΔS_abs` 严格成立，该耦合项**无法归属到任一具体因子**，诊断面板须额外解释「主项与短板同时变化」，抬高认知负载；按 Shapley 值分摊又引入分解顺序的任意性。故**不采纳**，改由下游 05 / UX 做数值披露（见下方约束），实现零返工。
>
> **为何不靠调参压残差**：把 `|100 ΔM ΔP|` 压到 ≤ 1 分需 `λ · |ΔL| · |ΔM| ≤ 0.01`；玩家一次性大改分区 / 拨付时 `|ΔM|` 可近 1、`|ΔL|` 可达 1，需 `λ ≤ 0.01`，而 `λ ∈ [0, 0.3]`、`f_floor ∈ [0.2, 0.5]` 均为**平衡期占位数值**（§8.1 / `systems-index.md` §7.1：平衡期定、S-12 前钉定、由配置表注入）。以设计裁定钉死它们既越权，也会让短板惩罚（防主导策略 ②）失去意义。**本裁定不调整任何占位参数。**

- **一致性要求（AC-F2 的残差判据只约束分解式内部）**：`| ΔS − (Σ_i ΔS_i + ΔS_penalty) | ≤ 1 分`（仅钳制残差允许）；**不得**据此要求 `ΔS = S_t − S_{t−1}`。钳制生效（`S` 触 0 / 100，或 `ΔS` 触 ±100）时按 **E4** 处理并标注「已达上下限」，不判归因链失真。
- 每条议题至少绑定 **1 个 `|ΔS_i|` 最大的因子** + 其来源明细（哪条通勤线 / 哪片覆盖不足 / 哪笔投入），由 05 组装。
- **下游披露约束（05 / UX 于 S-05 / S-09 落地，本轮不实现）**：当 `|ΔS_abs − ΔS| > 1 分`，或 `|ΔS_abs| > 1` 而 `|ΔS| ≤ 1` 时，诊断面板须显式说明「本次变化含主项与短板同时变化的耦合」或给出 `S` 的绝对变化数值，**不得让玩家看到 HUD 数字与归因之和明显对不上**（概念 §9.1 R4 反馈黑箱）。

## 6. 边界与 Won't

### 6.1 边缘情况（≥3 类，逐类给出处理原则）

| # | 边缘情况 | 处理原则 |
| --- | --- | --- |
| E1 | **冷启动首 tick 无 `Snapshot_{t−1}`** | **T-113 裁定措辞**：① 以「空城基线」构造 `f_i = f_init`、`S_{−1} = S_init`，其中 `f_init` 为**占位（由配置表注入，不写死）**，`S_init` 由 `f_init` 经 §4.2 合成公式**派生**、不单独钉定数值；② **首 tick `S_t` 仍按 §4.2 由实际四因子照算**，反映玩家首轮拨付与网格状态，**不得强制 `S_t = S_init`**；③ `ΔS`（归因分解量）`= 0`、`dS_by_factor` 全 0、`ΔS_penalty = 0`，**不生成归因型议题**，只给一条教学占位归因（由 05 处理）；④ **`ΔS_abs = S_t − S_{−1}` 允许 ≠ 0**，须由 Delta 条目记录供 HUD 显示，但不触发 V2 归因型诊断。第 2 tick 起 `t−1` 帧已是首 tick 的真实结果，正常产出归因链。 |
| E2 | **暂停态连续多次编辑后一次推进** | 编辑合并为单一 `input_version`，S0 一次性冻结；不得按编辑次数重复结算；即时反馈与模拟结果分离 |
| E3 | **分母为 0**：`P_t = 0` / `J_t = 0` / `Σ w_g = 0` / 无路网 / 不可达 OD | 全部走 `f = 0` 或 `T = T_max` 的兜底，**严禁除零与 NaN**；03 对不可达返回 `T_max` 而非 `∞` |
| E4 | **`S` 触边（0 或 100）** | 钳制后 `ΔS` 会失真；归因链仍按钳制前的主项贡献记录，并在 05 标注「已达上下限」 |
| E5 | **回退重试导致快照回滚** | 回退到周期初 `Snapshot`，`ΔS` 与 `dS_by_factor` 一并回滚；不得出现「S 回退但归因链未回退」的不一致 |
| E6 | **多因子同时恶化** | 由 05 按 `|ΔS_i|` 排序优先级，本系统只保证四个贡献值可比较、不丢失 |

### 6.2 Won't（明确不做）

- ❌ 不做与 `S` 并列的第二终局轴 / 独立财政评分（P1、OD-1 A）。
- ❌ 不做硬终局、Game Over、失败判负（OD-1 A）。
- ❌ 不做静态半径覆盖、不做瞬时结算（P3）。
- ❌ 不做具象个体市民模拟、不按个体聚合满意度（OD-3 A）。
- ❌ 不做分区级满意度差异（Should）、不做自动播放 / 倍速（Should）。
- ❌ 不定义引擎实现、API、存储结构、性能预算（架构职责，见第 8 节）。

## 7. 验收标准（可测）

| # | 验收项 | 判据 | 对应全局 AC |
| --- | --- | --- | --- |
| **AC-F1** | 四因子单调性 | 单独恶化任一输入（`T_c↑` / 覆盖↓ / `E↑` / `I_f↓`），对应 `f_i` 单调不增，且 `S` 不上升 | AC2 |
| **AC-F2** | 归因链可追溯（**T-113 措辞澄清，判定强度不变**） | ① **分解内部一致性**：`abs(ΔS − ΣΔS_i − ΔS_penalty) ≤ 1 分`（`abs()` 为绝对值记号，与原式同义；改用 `abs()` 仅为避免 Markdown 表格分隔符歧义），其中 `ΔS` 指 §4.3 的**归因分解量**（`Snapshot.dS`），**不要求** `ΔS = S_t − S_{t−1}`；钳制生效按 E4 标注，不判失真。② **变化可追溯**：任一 `S` 发生变化的 tick（`ΔS_abs ≠ 0`）或任一 `ΔS ≠ 0` 的 tick，诊断面板可给出 ≥1 条具体原因；**首 tick 按 E1 例外**（教学占位归因，不出归因型议题）。③ 耦合项数值披露按 §4.3 下游约束，由 05 / UX 在 S-05 / S-09 落地。 | **AC2** |
| **AC-F3** | 无主导策略 | 至少 **2 种显著不同**的分区/路网方案均可达 `S ≥ S_unlock`；参数扫描不存在唯一全局最优 | **AC3** |
| **AC-F4** | 快照可回放 | 给定同一 `Snapshot_{t−1}` 与同一输入，重复结算得到同一 `S_t`（确定性、无隐藏随机） | AC1 |
| **AC-F5** | 无硬终局 | 连续多个周期未达标，游戏不判负、可回退重试、议题仍可生成 | OD-1 A |
| **AC-F6** | 边缘健壮 | E1 ~ E6 全部无 NaN / 无除零 / 无崩溃，`S` 始终 ∈ `[0,100]` | AC1 |
| **AC-F7** | 滞后生效 | 暂停态编辑即时可见但 `S` 不变；点「结束本日」后 `S` 才变化 | OD-2 A / 锚点 8 |
