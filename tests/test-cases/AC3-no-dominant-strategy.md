## 2. 「方案差异度」可判定定义

> 本节是 AC3 的**判定基准**，不得在执行时临场解释。「明显不同」不是主观描述，是下列布尔函数 `Distinct(A,B)`。

### 2.1 正向条件（须同时满足①，且②~④中至少满足 1 条）

| # | 条件 | 可判定量 | 阈值 |
| --- | --- | --- | --- |
| **① 必选 · 分区拓扑不同** | R / C / I 三类格数占比向量不同，或三类分区块的**相对位置 / 邻接关系**至少一处不同（如「R 与 I 是否相邻」「C 是否居中」） | 三元组占比向量差、分区块邻接矩阵 | 占比差 ≥ `<Δ_zone>`（测试侧占位，需用户 / 主理人确认，见 `tests/test-strategy.md` §10.2 / §13 O-2） |
| ② 路网拓扑不同 | `ROAD` 格集合的连通结构不同（环 / 树 / 轴向 / 网格），不是同一骨架增删一条边 | `ROAD` 格集合 diff、连通结构标签、格数差 | 格数差 ≥ `<Δ_road>`（占位） |
| ③ 密度分布不同 | D1 / D2 / D3 格数分布向量不同，且**不是同一向量的整体缩放**（排除「同分布只整体放大密度」） | 三维分布向量 + 归一化后余弦差 | 归一化后向量不同 |
| ④ 达标路径不同 | 两方案 `|ΔS_i|` 最大的主因因子不同，或四因子贡献**排序**不同 | `dS_by_factor[4]` 排序 | 主因因子不同 或 排序不同 |

### 2.2 伪差异排除（命中任意一条即 `Distinct(A,B) = 假`）

1. 仅对同一布局做平移 / 镜像 / 旋转（最终 `Cell` 状态等价）。
2. 仅改动 1 个 `Cell`，或改动格数占比 ≤ `<Δ_zone>` 下限的微调。
3. 仅换配色 / 皮肤 / 文案 / 建筑外观变体。
4. 仅在同一路网骨架上增删 1 段支路、或仅改 1 段道路走向而不改变连通结构。
5. 仅改变 `<K>` 个 tick 内的**操作先后顺序**，而周期末 `Cell` 状态完全相同。
6. 仅改变 seed / `<K>` / `configHash` 之外不改变布局的运行参数（如只换会话时间）。
7. 仅把同一方案拆成「先做一半 / 后做一半」的两个时间切片。

### 2.3 判定输出（须可复核）

每条 `Distinct(A,B)` 判定输出固定四项：`真 / 假`、命中的正向条件编号（① 必含 + ②~④ 至少 1 条）、命中的伪差异编号（若有）、两份周期末 `Cell` 状态快照的 diff 文件路径。**无 diff 证据的判定不计入 AC3**。

### 2.4 与「微调一格」的界线（举例说明，非用例数据）

- 方案 A 与「A 把某一格 R 改成 C」→ 命中伪差异 2 → `假`。
- 方案 A 与「A 整体向右平移 2 格」→ 命中伪差异 1 → `假`。
- 方案 A（环状路网、紧凑混合、主因 `f_c`）与方案 B（轴向树状路网、功能分区、主因 `f_f`）→ 命中 ①②③④ → `真`。

## 3. 两套候选方案构造思路（仅结构与思路，不含任何具体数值）

> 以下为**构造思路**，用于生成可注入配置；具体格坐标、格数、`I_f`、`<S_unlock>` 等由平衡期配置表注入，本轮不填数。三套方案共用同一 `configHash` / seed / `<K>` / `<S_unlock>`，保证可比。

### 3.1 方案 A ·「紧凑混合 · 环状路网 · 通勤优先」

| 维度 | 构造思路 |
| --- | --- |
| 分区位置 | 在起始 16×16 解锁子集内**交错紧凑**布置 R / C / I；C 居中，R 环绕，I 贴近边缘；R 与 I 相邻 |
| 路网 | `ROAD` 构成**环 + 少量径向连接**，使 R→I（上班流）与 R→C（生活服务流）路径短、`q/cap` 低 |
| 密度 | 以中档为主、局部低档（D1/D2 混合），**非全图 D3** |
| 财政投入 | `I_f` 取中低水平（占位） |
| 预期达标路径 | 主因 `f_c` / `f_s`（通勤可达与服务覆盖），四因子较均衡 |
| 用途 | AC-F3 的达标解 1；AC-T2 的对照组 A |

### 3.2 方案 B ·「功能分区 · 轴向干道 · 财政与环境补偿」

| 维度 | 构造思路 |
| --- | --- |
| 分区位置 | R 与 I **分置解锁子集两端**（通勤距离拉长，但产业与居住分离降低 `f_e` 环境暴露）；C 沿轴向带状居中；**R 与 I 不相邻** |
| 路网 | `ROAD` 为**轴向主干 + 树枝状支路**（树状，非环），连通结构与 A 不同；`ROAD` 格数与 A 差 ≥ `<Δ_road>` |
| 密度 | D1 / D3 混合，分布向量与 A 不同且非整体缩放 |
| 财政投入 | `I_f` 取较高水平（占位），以 `f_f` 补偿较长通勤 |
| 预期达标路径 | 主因 `f_f` / `f_e`，与 A 的四因子贡献排序不同 |
| 用途 | AC-F3 的达标解 2；AC-T2 的对照组 B |

> **AC-T2 共用对照**：方案 A 与 B 的 **R/C/I 总格数与三类配比保持相同**，仅改变「道路连接 / 分区位置」，用于逐字验证 AC-T2「相同分区数量与配比，仅改变道路连接 / 分区位置，`T_c` 与 `S` 不同」。

### 3.3 方案 C ·「全图 D3」（AC-M5 反例对照）

| 维度 | 构造思路 |
| --- | --- |
| 分区位置 | 与 A 或 B 相同的分区轮廓，但所有 R/C/I 格均为 D3 |
| 预期 | **不达标，或不优于 A / B**（受 04 的 `C_m` 阶梯上升与 01 的 `f_e` 反制）；至少证明「全图 D3」不是唯一最优解 |
| 用途 | AC-M5「『全图 D3』不成为唯一最优解」的对照证据；`design/gdd/systems/02-map-zoning.md` §4「密度系数增幅递减，防全图拉满 D3 成为主导策略」 |

### 3.4 配置注入清单（每份方案回放必须齐备的字段）

```
PlanConfig = {
  planId, planLabel,
  cells: { R: [(x,y)...], C: [...], I: [...], ROAD: [...], EMPTY: [...] },  // 结构，不填数值
  density: { D1: [...], D2: [...], D3: [...] },
  I_f: <占位>,
  K: <K>, S_unlock: <S_unlock>, T_max: <T_max>, i_ref: <i_ref>,
  w_i: <w_i>, α: <占位>, λ: <占位>, f_floor: <占位>,
  configHash, schemaVersion, engineVersion, prngSeed
}
```

- 同一 `configHash` 下 A / B / C 分别回放；任一配置变更须升 `configHash`，旧快照走显式迁移或拒绝载入（ADR-003 A3 / S-02 验收 2）。
- 参数扫描的维度与步数由平衡期定（占位），本轮不编造扫描范围。

| 字段 | 内容 |

### TC-AC3-14 · Expression 主观复核（不同玩家长出形态不同的城市）

| 字段 | 内容 |

| 用例 ID | `TC-AC3-14` |

| 前置条件 | 可玩垂直切片；`<N_playtest>` 名受试者（可与 AC1 同批，但须为**第二次会话**且分别标注）；无外部说明；主持脚本按 `tests/test-cases/AC1-onboarding.md` §1.2 / §1.3 |
| 测试数据 | 每名受试者第二次会话的周期末 `Cell` 快照 / 存档；「如果重来一次会怎么规划」访谈回答；城市形态截图 |

**编号步骤**

1. 每名受试者在无提示下完成第二次会话，导出周期末 `Cell` 状态快照。

**预期结果（可观测 / 可判定）**

- E1 至少存在 2 名受试者的周期末 `Cell` 快照满足 `Distinct = 真`（命中的正向条件编号可列出）。
- E2 访谈中出现 ≥2 种不同的规划意图表述（如「先连路」vs「先分区」），且不由主持人提示产生。
