## 0. 使用说明（执行前必读）

1. **先过准入门**：执行前须通过 `tests/test-strategy.md` §5.1 准入门 A-1~A-7，特别是 A-5「受试者招募方案」与 A-6「测试侧占位参数确认」；GAP-04（O-4 主持脚本与知情同意批准）、GAP-02（`<N_playtest>` / `<T_idle>` / `<T_slow_ceiling>`）、GAP-03（AC4 计时口径）须已关闭。
2. **主持人禁用清单**：`tests/test-cases/AC1-onboarding.md` §1.3 六条逐字执行。命中禁用项 → 该会话判 `INVALID`，须更换会话重测；仅三类允许干预情形（应用崩溃 / 受试者明确说「我想结束」/ 达到 10 min 上限）可记录。
3. **唯一允许的开场话术**（逐字，不得临场发挥）：
   > 「这是一次游戏体验测试。请像平时玩一款新游戏那样开始，全程按你自己的想法操作。过程中我不会解释规则，也不会回答关于玩法的问题。遇到问题请继续尝试，或随时说『我想结束』。全程录屏与计时，仅用于研究。」
4. **零外部说明**：不提供说明书、教程卡、截图、网页、`design/` / `docs/` / `production/` 任一文档或内部演示。
5. **脱敏**：受试者以 `<subject-id>` 标识，报告内不出现姓名、联系方式、可识别影像；知情同意与录音单独存放于 `tests/evidence/<batch-id>/playtest/<subject-id>/`，仅授权人员可访问。
6. **占位符纪律**：`<K>` / `<S_unlock>` / `<T_max>` / `<i_ref>` / `<N_playtest>` / `<T_idle>` / `<T_slow_ceiling>` 等一律不填编造数值；性能数字一律「建议基线 / 非承诺值」（`tests/test-strategy.md` §10）。
7. **切片边界**：本报告不记录、不评价公共交通 / 政策卡 / 地价 / 多道路等级 / 独立危机事件 / 跨设备 / 折叠屏双栏 / 季节昼夜 / 成就 / 分享 / 具象个体市民 / 无尽地图 / 付费加速 / ×1×2×4 倍速 / 自动播放 / 倒计时条 / H1~H4 平台特性；折叠展开态与平板**仅作性能测量形态**（`tests/test-strategy.md` §4.2 / §11）。
8. **质量门为 advisory**：本报告给出 PASS / CONCERNS / FAIL 建议，**最终放行由用户决定**；发布签字等高影响动作须人工审批（`tests/test-strategy.md` §5.3 / §8）。
